## 🌟 Project Overview

**Rajan - Castle Properties** is a comprehensive, production-grade 2026 luxury real estate and land investment platform engineered specifically for **Hyderabad's ultra-premium corridors** (*Kokapet, Neopolis, Financial District, Tellapur*) and the rapid industrial and economic transformation taking place in **Telangana's Fourth City** (*Mirkhanpet, Maheshwaram, Kadthal*).

The platform mirrors the visionary real estate enterprise founded by **Mr. Katla Bhagyarajan**, offering high-net-worth individuals, institutional investors, and first-time plot buyers a transparent, data-driven window into Hyderabad's real estate potential.

### 🎯 Core Highlights & Vision
- **Founder's Visionary Leadership:** Inspired by Mr. Katla Bhagyarajan’s middle-class upbringing, 16+ years in private corporate leadership, and a steadfast commitment to delivering *simpler, smaller, and smarter* plot and villa ventures.
- **Fourth City Mega-Corridor Focus:** Direct alignment with Telangana Government master plans, including the **Young India Skill University**, the **₹5,809 Crore Amazon Data Center campus**, proposed **Regional Ring Road (RRR)** junctions, and the **300ft Raviryal-to-Meerkhanpet Greenfield Highway**.
- **Modern Obsidian & Metallic Gold Aesthetic:** Deep obsidian-950 (`#030712`) palettes paired with warm gold accents (`#C5A059`), glassmorphism, and responsive card layouts designed to reflect bespoke luxury.
- **End-to-End Enterprise CRM:** Integrated inquiry pipeline, automated reference code generation, multi-stage VIP lead tracking, and chauffeur-driven site visit dispatch tools for real estate operations teams.

Before running the application locally, ensure you have the following installed on your workstation:

- **Node.js**: `v18.0.0` or higher (Node 20 LTS recommended) & `npm 9+`
- **Java Development Kit (JDK)**: `Java 21 LTS` (Eclipse Temurin or OpenJDK 21)
- **Apache Maven**: `v3.9.0` or higher
- **MongoDB**: `v7.0` or `v8.0+` running locally or accessible via network URI

## 🚀 Quick Start (Local Development)

### 1. Clone Repository

```bash
git clone https://github.com/vydyapavankalyan/Real-estate-venture-website.git
cd Real-estate-venture-website
```

---

### 2. MongoDB Setup

Ensure your local MongoDB instance is active on the default port `27017`.  
The database name used by default is `venture`.

```bash
# Verify MongoDB service status (Linux / macOS)
sudo systemctl status mongod

# Or run via standalone Docker container if you do not have local MongoDB:
docker run -d --name local-mongo -p 27017:27017 -v mongo_dev_data:/data/db mongo:8.0
```

---

### 3. Backend Launch

The backend uses Spring Boot with an automatic `DataSeeder` that seeds initial users, Fourth City projects (Mirkhanpet, Maheshwaram), locations, blogs, and test leads upon startup.

```bash
# Navigate to the backend directory
cd backend

# Build and run the Spring Boot application
mvn clean spring-boot:run
```

- **Backend API Base URL:** `http://localhost:8085`
- **Interactive Swagger UI:** `http://localhost:8085/swagger-ui.html`
- **OpenAPI JSON Spec:** `http://localhost:8085/v3/api-docs`

---

### 4. Frontend Launch

Open a new terminal window:

```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies
npm install

# Start Vite development server
npm run dev
```

- **Frontend Web Portal:** `http://localhost:5173`
- The Vite development server automatically proxies `/api` and `/uploads` requests directly to `http://localhost:8085`.

## 🐳 Docker Multi-Container Deployment

The repository includes complete multi-stage Dockerfiles and a coordinated `docker-compose.yml` to spin up the entire ecosystem (MongoDB 8.0 + Spring Boot 3.3.4 + Nginx React Frontend) with one command.

### Spin Up Containers

```bash
# From project root directory
docker compose up --build -d
```

### Check Container Health

```bash
docker compose ps
```

You should see 3 running containers:
1. `hyderabad-realestate-mongodb` (port `27017:27017`)
2. `hyderabad-realestate-backend` (port `8085:8085`)
3. `hyderabad-realestate-frontend` (port `80:80`)

### Access Production Endpoints
- **Production Web Application:** `http://localhost` (or `http://YOUR_SERVER_IP`)
- **Backend REST API:** `http://localhost:8085/api`
- **Swagger Documentation:** `http://localhost:8085/swagger-ui.html`

### View Real-Time Logs

```bash
# View backend logs
docker compose logs -f backend

# View frontend / Nginx logs
docker compose logs -f frontend
```

### Stop Containers

```bash
docker compose down
```

## 📡 API Endpoints Summary

All backend APIs are prefixed with `/api` and return standardized responses wrapped in `ApiResponse<T>`.

### 🔑 Authentication & Users (`/api/auth`)
| Method | Endpoint | Access | Description |
|---|---|---|---|
| `POST` | `/api/auth/login` | Public | Authenticate user with email and password; returns JWT & refresh token |
| `POST` | `/api/auth/register` | Public | Register prospective user or internal staff member |
| `POST` | `/api/auth/refresh-token` | Public | Obtain new access token via valid refresh token |
| `GET` | `/api/auth/me` | Authenticated | Retrieve authenticated user profile and roles |

### 🏘️ Projects & Ventures (`/api/projects`)
| Method | Endpoint | Access | Description |
|---|---|---|---|
| `GET` | `/api/projects/featured` | Public | Fetch curated featured projects for home and highlight carousels |
| `GET` | `/api/projects/search` | Public | Multi-criteria search (location, type, BHK, price range, status, page) |
| `GET` | `/api/projects/{slug}` | Public | Get full project details by unique URL slug |
| `GET` | `/api/projects/id/{id}` | Public | Get project details by internal database ID |
| `POST` | `/api/projects` | Admin / Manager | Create a new real estate venture listing |
| `PUT` | `/api/projects/{id}` | Admin / Manager | Update an existing venture (pricing, gallery, specs) |
| `DELETE`| `/api/projects/{id}` | Admin Only | Delete a project listing |

### 📍 Locations & Corridors (`/api/locations`)
| Method | Endpoint | Access | Description |
|---|---|---|---|
| `GET` | `/api/locations` | Public | Retrieve all active Hyderabad & Fourth City locations |
| `GET` | `/api/locations/featured`| Public | Retrieve featured corridors (Mirkhanpet, Kokapet, Maheshwaram) |
| `GET` | `/api/locations/{slug}` | Public | Fetch corridor overview, price trends, and infrastructure links |
| `POST` | `/api/locations` | Admin / Manager | Add a new location or growth corridor |
| `PUT` | `/api/locations/{id}` | Admin / Manager | Update location details or connectivity highlights |
| `DELETE`| `/api/locations/{id}` | Admin Only | Remove a location record |

### 📋 Enquiries & Lead Pipeline (`/api/enquiries`, `/api/leads`)
| Method | Endpoint | Access | Description |
|---|---|---|---|
| `POST` | `/api/enquiries` | Public | Submit homebuyer inquiry; auto-generates tracking reference code |

| `GET` | `/api/leads/{id}` | Staff / Admin | Get full lead dossier, property interest, and timeline |
| `PUT` | `/api/leads/{id}/status`| Staff / Admin | Update lead pipeline stage (`NEW` → `QUALIFIED` → `CONVERTED`) |
